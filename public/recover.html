What is a backup code?

It’s one of the long, single-use codes you saved when setting up Security & recovery. Look in your downloaded file, printed copy, or password manager.

A backup code has 8 groups of 4 letters or numbers. It is not your password or the six-digit code shown in your authenticator app.

Code not working?

Use the app entry for this portal, not a code for another account. Let a new code appear before trying again; an already-used code won’t work twice. Check that your phone’s date and time are automatic.

Text delivery may take a moment. Check your signal and message filters. Only the phone you verified earlier can receive it; delivery is not guaranteed.

To request another text, wait for the button below, then check your details and enter your backup code again. Texts are never resent automatically.

A used or incorrect backup code, an unavailable recovery method, or an expired request can also prevent verification.
