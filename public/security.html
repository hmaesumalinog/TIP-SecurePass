Before you start

You’ll need a compatible authenticator app on your phone. It creates a new six-digit code about every 30 seconds—even without an SMS.

What do I choose in the app?

Look for Add account or the + button. Choose scan QR code, or enter a setup key manually with a time-based code. You’ll add this account in the next step.

Confirm it’s you

Enter the password you use to sign in to this student portal.

Use your existing app to approve replacement. Wait for a new code if you just used the previous one.

Add this account to your app

In your authenticator, choose Add account and scan this QR code. The account will appear as Reset Workflow.

Using this page on your phone?

Enter the key below manually in your app. Choose a time-based, six-digit code. Name the account “Reset Workflow”.

Keep this QR code and setup key private.

Enter the changing code under Reset Workflow—not an SMS or a backup recovery code.

A quick explanation

                
Three different things.
One safer account.

                

                  
Portal password

                  
The password you use to sign in.

                  
Authenticator code

                  

                    A six-digit code that changes in your app. It is not sent by
                    text.
                  

                  
Backup recovery code

                  

                    A longer, single-use code you save now and use only when
                    recovering your account.
                  

                

              

              

                
Good to know

                

                  Why do I need this setup?
                  

                    It gives you another way to reset your password if you
                    cannot open your email. New and existing students without an
                    authenticator must enroll before portal access.
                  

                

                

                  I moved from an older portal.
                  

                    Follow the status shown here for this account. If it says
                    Not set up, connect an authenticator even if you used one
                    with a different service. Keep signing in with your assigned
                    student number and current portal password.
                  

                

                

                  Will sign-in change?
                  

                    No. You still sign in with your student number and password.
                    The authenticator is for account recovery and approving
                    security changes.
                  

                

                

                  What if I lose my phone?
                  

                    If you cannot use an enrolled method, request administrator
                    assistance. A request does not automatically reset your
                    password; staff must verify ownership.
