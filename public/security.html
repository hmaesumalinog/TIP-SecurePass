Before you start

Install a free authenticator app on your phone. It shows a new six-digit code about every 30 seconds—no SMS needed. Any of these work:

  • Google Authenticator
  • Microsoft Authenticator
  • Authy
  • 2FAS

    A quick explanation

    Three different things.
    One safer account.

    Portal password
    The password you use to sign in.
    Authenticator code
    A six-digit code that changes in your app (listed as Reset Workflow). It is not sent by text.
    Backup recovery code
    A longer, single-use code you save now and use only when recovering your account.

    Good to know

    Why do I need this setup?

    It gives you another way to reset your password if you cannot open your email. New and existing students without an authenticator must enroll before portal access.

    I moved from an older portal.

    Follow the status shown here for this account. If it says Not set up, connect an authenticator even if you used one with a different service. Keep signing in with your assigned student number and current portal password.

    Will sign-in change?

    No. You still sign in with your student number and password. The authenticator is for account recovery and approving security changes.

    What if I lose my phone?

    If you cannot use an enrolled method, request administrator assistance. A request does not automatically reset your password; staff must verify ownership.
